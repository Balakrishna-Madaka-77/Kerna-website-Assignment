# Kerna – Where Strategy Meets Spark

Kerna is a modern, strategy-driven PR and marketing agency website designed for small businesses, startups, and independent brands.  
This is a fully responsive **static multi-page website** built using HTML, Tailwind CSS, custom CSS, and JavaScript with dark/light theme support.

---

## 📁 Project Structure

kerna-website/
├── Assign.html        # Home page
├── work.html          # Work / Projects page
├── careers.html       # Internship opportunities
├── contact.html       # Contact & application form
├── Assignment.css     # Custom premium styling
├── theme.js           # Dark / Light theme toggle
└── README.md          # Project documentation

---

## 🚀 Features

- Clean and professional UI design  
- Dark / Light mode toggle with localStorage support  
- Responsive layout using Tailwind CSS  
- Multi-page navigation (Home, Work, Careers, Contact)  
- Internship application form with success message  
- Embedded Google Maps location  
- Smooth hover effects and transitions  
- Custom premium CSS styling

## 🌍 Live Deployment (GitHub Pages)

### How to Deploy:
1. Create a GitHub repository (example: `kerna-website`)
2. Upload all project files to the repository root
3. Go to **Settings → Pages**
4. Select:
   - Branch: `main`
   - Folder: `/root`
5. Save changes

### Live URL Format:
https://YOUR-GITHUB-USERNAME.github.io/kerna-website/Assign.html
